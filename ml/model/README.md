# ML Model

This branch contains the machine learning model development pipeline for EAMS.

## Responsibilities

- Model training
- Model selection
- Hyperparameter tuning
- Model evaluation
- Performance comparison
- Model serialization

## Evaluation

The model should be evaluated using appropriate performance metrics for the selected prediction approach.
