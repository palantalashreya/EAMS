# ML Data Preparation

This branch contains the data preparation pipeline for the EAMS machine learning system.

## Responsibilities

- S-OH dataset cleaning
- Missing-value handling
- Data validation
- Feature selection
- Feature engineering
- Data preprocessing
- Preparation of data for model training

## Important

The preprocessing pipeline should use features that can ultimately be obtained from the EAMS sensing system or its validated data sources.

## Workflow

Raw Data
↓
Data Cleaning
↓
Missing Value Handling
↓
Feature Engineering
↓
Feature Selection
↓
Processed Dataset
↓
ML Model
