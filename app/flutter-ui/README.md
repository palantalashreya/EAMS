# Flutter UI

Flutter frontend for the EAMS application.

## Planned Screens

### 1. Test

Allows the user to:

- Start a breath test
- View test instructions
- Monitor test progress

### 2. Result

Displays:

- Screening risk level
- Prediction confidence
- Appropriate follow-up message

### 3. History

Displays:

- Previous tests
- Previous risk results
- Test date and time
